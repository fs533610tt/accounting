# 🚀 未來擴充與部署指南 (Expansion & Deployment Guide)

本系統從設計之初即採用 **多租戶架構 (Multi-Tenancy)**。這代表系統天生就能夠同時服務多支不同的球隊（例如：福山國小、左營國小），且彼此的資料完全獨立。

如果您未來希望讓其他學校或球隊也能使用這套系統，您可以根據需求選擇以下兩種擴充方式。這份指南將手把手教您（或未來的接手者）如何操作。

---

## 方式一：直接共用本系統 (SaaS 雲端服務模式)

**適用情境**：您願意統一管理所有球隊，且其他球隊不介意跟您共用同一個網址。
這是最省事、最推薦的做法，您**不需要重新架設任何東西**。

### 📝 詳細操作步驟：
1. **建立新球隊**：請您以「最高管理員 (Super Admin)」的身分登入目前的系統。
2. **新增球隊資料**：在系統的「👑 系統管理中心」，點擊建立一支新球隊（例如輸入：左營國小桌球隊）。
3. **指派對方權限**：請對方教練先在您的網址使用 Google 登入過一次。接著您在「系統管理中心」點擊「指派管理員」，輸入對方教練的 Google 信箱。
4. **開始使用**：完成！當對方教練再次登入時，系統的安全規則 (RLS) 會自動隔離資料。對方**只能看到自己球隊的小朋友與帳單**，絕對看不到福山國小的資料。

---

## 方式二：完全獨立搬出 (系統賣斷 / 獨立部署)

**適用情境**：其他學校堅持要擁有「專屬自己的網址」以及「獨立掌握的資料庫」，資料完全不與任何人放在一起。
這會需要重新架設一次系統，但請放心，所有的設定都已經模組化，請嚴格按照以下步驟執行：

### 第一步：建立新的資料庫 (Supabase)
1. 請前往 [Supabase 官網](https://supabase.com/)，註冊一個全新的免費帳號。
2. 點擊 `New Project`，建立一個新的專案 (Project Name 可以取名為該學校的英文簡寫)。
3. 等待幾分鐘，直到專案建立完成進入主控台 (Dashboard)。
4. 在左側選單找到 **Authentication** -> **Providers**，啟用 **Google** 登入（您需要去 Google Cloud Console 申請一組 Client ID 與 Secret，這部分請參考 Supabase 官方文件）。

### 第二步：執行資料庫建置腳本 (Database Migrations)
1. 在 Supabase 左側選單找到 **SQL Editor**。
2. 請打開本專案 `docs/sql/` 目錄下的所有 `.sql` 檔案。
3. **🚨 非常重要**：請務必依照檔名開頭的數字順序（`01`, `02`, `03` ... `07`），依序將檔案內容複製、貼上到 SQL Editor 並點擊 `Run` 執行。
4. 只要依照順序執行完畢，資料表、安全規則、自動化函數就全部建立完成了！

### 第三步：設定前端程式碼與金鑰
1. 將這整包程式碼 (GitHub 專案) 完整複製/下載一份給對方。
2. 回到 Supabase 主控台，點擊左下角的 ⚙️ **Project Settings** -> **API**。
3. 找到 `Project URL` 與 `anon public` 這兩把金鑰。
4. 在對方電腦的程式碼最外層，建立一個檔案叫做 `.env`。
5. 將剛才拿到的金鑰貼進去（請替換為真實字串）：
   ```env
   VITE_SUPABASE_URL=您的_Project_URL
   VITE_SUPABASE_ANON_KEY=您的_anon_public_key
   ```

### 第四步：發布網站
1. 在對方電腦打開終端機 (Terminal)，確保已經安裝 Node.js。
2. 執行 `npm install` 安裝所有需要的套件。
3. 執行 `npm run deploy`，這會自動把網頁打包並發布到對方的 GitHub Pages 上。

### 第五步：開通第一位「最高管理員」 (系統破關關鍵！)
由於新系統預設沒有任何人有權限，因此我們必須手動將第一個人（也就是您或該校負責人）升級為 Super Admin，系統才能開始運作。
1. 請前往剛剛發布成功的網站，使用 Google 登入一次 (為了讓系統記錄下這個信箱)。
2. 回到 Supabase 主控台，點擊左側 **Table Editor**，進入 `auth.users` 資料表，複製您剛剛登入的那筆帳號的 `id` (一長串亂碼 UUID)。
3. 切換到 `public.user_roles` 資料表，點擊 **Insert row** (新增一筆資料)。
4. 填寫以下欄位：
   - `user_id`: 貼上剛剛複製的 UUID
   - `team_id`: **留白 (NULL)**
   - `role`: 輸入 `superadmin`
5. 按下 Save。回到網頁按下 F5 重新整理。
6. 只要畫面上出現 **「👑 系統管理中心 (Super Admin)」**，恭喜您！一套全新的專屬系統已經成功上線，您可以開始建立球隊了！
